Ejercicios prácticos de la Unidad 2.

## Práctica

| Apunte | Tema |
|---------|------|
| [Práctica — Importación de archivos](/bbdd-aplicadas/unidad-2/practica/importacion-archivos/) | 6 ejercicios: BULK INSERT con comillas y codificación, staging y validación, ancho fijo, JSON y XML con OPENROWSET |
| [Trabajo Práctico 2](/bbdd-aplicadas/unidad-2/practica/tp2/) | TP 2 (15 ejercicios, red de estaciones de aire): collation y sus conflictos, importación de CSV con UTF-8, validación y limpieza, tablas temporales y variables de tabla, percentiles |
| [Práctica — Transacciones](/bbdd-aplicadas/unidad-2/practica/transacciones/) | BEGIN/COMMIT/ROLLBACK, TRY/CATCH, SAVEPOINT, XACT_ABORT, aislamiento. Corresponde a la Unidad 3 según el programa 2024 y se trasladará allí conservando esta dirección |
| [Práctica — JSON en SQL Server](/bbdd-aplicadas/unidad-2/practica/json/) | 7 ejercicios: OPENJSON con y sin WITH, JSON_VALUE/QUERY/MODIFY, FOR JSON PATH/AUTO |
| [Práctica — XML en SQL Server](/bbdd-aplicadas/unidad-2/practica/xml/) | 7 ejercicios: tipo xml, .value/.nodes/.exist, OPENXML y FOR XML RAW/AUTO/PATH |
| [Práctica — BD en memoria (In-Memory OLTP)](/bbdd-aplicadas/unidad-2/practica/bd-en-memoria/) | Filegroup en memoria, tablas MEMORY_OPTIMIZED, durabilidad y comparación con tablas en disco |
| [Práctica — APIs desde SQL Server](/bbdd-aplicadas/unidad-2/practica/apis/) | Complementario: parseo y persistencia de respuestas JSON; llamadas con Ole Automation y sus riesgos |
